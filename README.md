# Network Infrastructure and IT Equipment Inventory

This project brings together the IT equipment inventory and network documentation for a textile company. It includes a network diagram, a Packet Tracer file, and equipment inventory documents.

## Project Files

- `INVENTAIRE EQUIPEMENT(3).xlsx` — equipment inventory spreadsheet.
- `pcglpi.pdf` — GLPI export listing computer equipment, its status, manufacturer, model, operating system, and location.
- `schema reseau.zip` — network schema files.
- `shema.pkt` — Cisco Packet Tracer project.
- `schema.txt` — link to the network diagram on diagrams.net.

## Equipment Inventory

The GLPI export is dated **18 June 2026** and lists **138 equipment records**. The records include computer names, service status, manufacturer, model, operating system, and department or location.

## Network Diagram

The network diagram can be viewed in diagrams.net:

[Open the network diagram](https://app.diagrams.net/#G1m1ES7vOZcvLFmJELAm1up0YuPYALzDEa#%7B%22pageId%22%3A%22UC140%22%7D)

The Packet Tracer file (`shema.pkt`) can be opened with Cisco Packet Tracer to inspect the network topology.

## How to Use

1. Download or clone this repository.
2. Open the Excel file to browse the equipment inventory.
3. Open `pcglpi.pdf` to consult the GLPI equipment list.
4. Open the diagram link to view the network schema.
5. Open `shema.pkt` in Cisco Packet Tracer to inspect the simulated network, if supported by your installed version.

## Notes

- Equipment details reflect the supplied inventory and GLPI export.
- The GLPI PDF reports 138 records as of 18 June 2026.
- Make sure you have Excel or a compatible spreadsheet application, a PDF reader, diagrams.net access, and Cisco Packet Tracer if you want to open all project files.
